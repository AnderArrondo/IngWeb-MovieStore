
# IngWeb-MovieStore

## Descripción
El proyecto "MovieStore" deberá implementar un sitio web en el que se muestre información sobre diferentes "movies" (películas y series). Los visitantes podrán ver los detalles de cada "movie" y encontrarlas en función del género (Drama, Acción, Suspense, Ciencia Ficción, etc.) y de los diferentes directores (Steven Spielberg, Christopher Nolan, Tarantino, etc.), teniendo en cuenta que puede haber "movies" dirigidas por más de un director. También podrán ver los detalles de cada género y director, incluida la lista de "movies" asociadas en cada caso.

## Funcionalidades Básicas
- Personalización de una plantilla (estructura de varios niveles) y sus estilos.
- Visualizar la portada de "MovieStore", mostrando una película de cada género (p.ej. la más reciente o el criterio que queráis).
- Visualizar la lista de películas, que además permita ir a otra vista para ver los detalles de una película en concreto, incluido a qué género pertenece y la lista de sus directores.
- Visualizar la lista de géneros, que además permita ir a otra vista para ver los detalles de cada género, incluida la lista de películas pertenecientes a el mismo.
- Visualizar la lista de directores, que además permita ir a otra vista para ver los detalles de un director, incluida la lista de películas asociadas al mismo.
